# MAPA_PLANOS

## 1. Estrutura de Planos
Os planos são divididos por portal e periodicidade.

| Plano | Portal | Periodicidade |
| :--- | :--- | :--- |
| **Clube Mensal** | Clube | Mensal |
| **Formação Orácula** | Orácula | Anual |
| **Jornada Heroína** | Aluna | Único |

## 2. Mapeamento de Ofertas (Rockty)
Cada oferta na plataforma Rockty deve apontar para um plano no banco de dados.

## 3. Regras de Upgrade/Downgrade
- Upgrades são processados via nova venda e cancelamento da anterior.
- Downgrades ocorrem no fim do período de vigência.
