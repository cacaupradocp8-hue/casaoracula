# MANUAL_GUARDIA_ADMIN

## 1. Responsabilidades
- Manter a saúde técnica do ecossistema Casa Orácula.
- Gerenciar permissões de acesso (Admin, Facilitadora, Aluna).
- Monitorar integrações financeiras (Rockty).

## 2. Fluxos Críticos
- **Onboarding:** Garantir que o de/para de ofertas está correto.
- **Segurança:** Revisar logs de auditoria e RLS.
- **Configurações:** Gerenciar chaves de API e segredos.

## 3. Ética e Segurança
- Nunca compartilhar credenciais de Admin.
- Respeitar a privacidade dos dados das usuárias.
- Seguir os protocolos de "Somente Leitura" para auditorias.
